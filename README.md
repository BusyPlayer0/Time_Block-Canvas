# 🧩 时间块·画布

> 一个可视化、可拖拽的每日时间规划工具，像拼图一样安排你的任务。

传统日历按小时列表不够直观。这个应用把一天 24 小时抽象成一个横向时间轴画布，你可以用鼠标拖拽出任意长度的时间块，并为每个块赋予颜色、标签和备注。拖拽时自动吸附到 15 分钟刻度，并实时计算每个类别的总耗时，以环形图展示。

---

## 功能一览

### 🎨 画布拖拽
- 在时间轴空白处**按住鼠标拖动**即可创建时间块
- 自动**吸附到 15 分钟**刻度
- 拖拽块本体可**移动**，拖拽左右边缘可**缩放**
- 禁止重叠——创建/移动/缩放时自动撞墙吸附到邻块边缘

### 🏷️ 类别管理
- 预置 工作、学习、休息、运动、睡眠 五个类别
- 可新增自定义类别（选择名称和颜色）
- 每个时间块可指定类别、填写标签和备注

### 📅 双视图
- **日视图**：单日 24h 横向时间轴，精确安排
- **周视图**：周一至周日 7 天同屏对比，支持每行直接拖拽

### 🎤 语音识别
- **语音添加块**：说"明天下午3点到5点学习数学"，自动解析并创建
- **语音输入**：标签/备注/类别名输入框支持语音听写填文字
- 5 秒不说话自动停止

### 📊 统计可视化
- SVG 环形图，展示各类别时间占比
- 日视图统计当天，周视图统计整周

### 💾 数据持久化
- 自动保存到浏览器 localStorage
- 支持**导出/导入** JSON 文件备份数据
- 清空当天 / 清空全部

### ⌨️ 键盘快捷键
| 按键 | 功能 |
|------|------|
| `←` / `→` | 前一天 / 后一天（日视图）；前一周 / 后一周（周视图） |
| `Delete` / `Backspace` | 删除选中块 |
| `Esc` | 取消选中 |

## 技术栈

| 层 | 技术 |
|---|---|
| **HTML** | 单文件自包含（index.html） |
| **CSS** | 原生 CSS，CSS 变量，Flexbox，SVG 环形图 |
| **JS** | 原生 JavaScript，零框架零依赖 |
| **存储** | 浏览器 `localStorage`（自动） + JSON 文件（手动导入/导出） |
| **语音** | Web Speech API（`webkitSpeechRecognition`），zh-CN |
| **兼容** | Chrome / Edge 完整支持；Firefox 等不支持语音，其余功能正常 |

## 使用方式

1. **下载** `index.html` 到本地
2. **双击**用浏览器打开（推荐 Chrome / Edge）
3. 点击 **「今天」** 定位当前日期
4. 在画布空白处**拖动**创建时间块
5. 点击块可编辑标签、备注、类别
6. 切换**日/周**视图查看整体安排

> 💡 语音功能需要网络（Web Speech API 云端识别），首次使用会请求麦克风权限。
